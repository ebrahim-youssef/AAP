# Website UI kit — Ali Amin Pharmacies

Click-through recreation of the **Clear Shelf** (2b) website, composed from the design-system components (`window.DesignSystem_032903`).

- `index.html` — mobile (390×844): Home → search results → product → WhatsApp confirm sheet; tabs for pharmacist and branches.
- `desktop.html` — desktop: hero search, results list + side detail panel with inline branch choice and WhatsApp link.
- `data.js` — **sample** products/prices (illustrative only), branch placeholders, WhatsApp placeholder number `200000000000`.
- Screens: `HomeScreen.jsx`, `ResultsScreen.jsx`, `ProductScreen.jsx`, `ConfirmSheet.jsx`, `PharmacistScreen.jsx`, `BranchesScreen.jsx`, `MobileApp.jsx`, `DesktopApp.jsx`.

Branch data is intentionally unverified — cards show «بيانات تتوثّق» until the owner supplies confirmed addresses/hours.
