# صيدليات علي أمين — Design System Draft v0.9

**الحالة:** Draft للمراجعة، غير مجمّد.  
**النطاق:** Brand + UI + UX + social visual system؛ Arabic-first/RTL-first، English ثانوي، light theme فقط، motion هادئ.

## المدخلات الثابتة

الاسم الرئيسي هو **صيدليات علي أمين / Ali Amin Pharmacies**. «د.» ليس جزءًا من اسم البراند؛ المؤسس يبقى مصدر تاريخ وثقة، من غير أن يبقى هو الواجهة الوحيدة للخدمة. القيم التشغيلية: الثقة، المهنية، الاعتمادية، السهولة، والاتساق. الموقع أداة مفيدة: **ابحث → شاهد آخر سعر معروف → أرسل لتأكيد التوفر → اختر الفرع أو التوصيل**. لا يوجد mission أو vision في هذا النظام عمدًا.

### الصوت المستورد

مصري طبيعي، مباشر، فاهم، صريح، وإنساني. المعلومة قبل التسويق، والاهتمام يظهر في الفعل. لا لغة صيدليات آلية ولا hype أو fake hooks. تقل العفوية وتزيد الدقة فورًا في الجرعات، الأطفال، الحمل، التداخلات، والأعراض الخطرة. نصوص الموقع أقصر من منشورات السوشيال: «دور بالاسم» بدل مقدمات طويلة.

## Design thesis

**العلامة التي تنظّم المعلومة وتسهّل الخطوة التالية.**  
بدل أن ننافس الصفوف المألوفة من blue/white/capsule/leaf أو واجهات السوبرماركت الطبي، النظام يبني الثقة من علامات صغيرة متكررة: سعر بتاريخ واضح، تنبيه صريح أن التوفر يحتاج تأكيدًا، موقع فرع قابل للتنفيذ، ومسار محادثة إنساني مع صيدلي. الأزرق يظل علامة المكان، لكن يكتسب عمقًا دافئًا ومساحات ورقية مريحة لكي يبدو مألوفًا ومحترفًا لا سريريًا أو باردًا.

### ما نستعيره من category — وما نتجنبه

واجهات الصيدليات المصرية تعتمد بكثافة على الأزرق، اللافتات الثنائية، وأرقام التواصل والخدمة السريعة. هذا مفيد كإشارة فورية للفئة، لكنه يجعل الأيقونات الطبية والواجهات البيضاء الحادة متشابهة. نحافظ على الوضوح الثنائي وسرعة الوصول، ونتجنب: الكبسولات والأوراق كفكرة شعار، اللون الأخضر كافتراض، صور stock لأطباء يبتسمون، عروض مزدحمة، وادعاءات صحية عامة.

## الهوية البصرية

### الشعار والـwordmark

الاتجاه الموصى به: **wordmark عربي مُفصّل هو البطل**: «علي أمين» بخط هندسي لين، عريض باعتدال، مع «صيدليات» كتعريف أصغر متماسك. الإنجليزية `ALI AMIN PHARMACIES` تعمل كمرافقة، لا كبديل متساوٍ.

لا يُطلب رمز مستقل في المرحلة الأولى. إذا احتاج النظام إلى علامة صغيرة لاحقًا، تُشتق من وصلة/نقطة الحروف العربية أو من شكل **سطرين متجاورين يوحيان بالرفّ المنظم**؛ لا من + أو قلب أو ورقة أو كبسولة. يحفظ ذلك الاسم ويزيل الاعتماد على صورة طبية generic.

**قواعد الاستخدام:** مساحة حماية = ارتفاع كلمة «علي» حول الشعار. يوضع على Paper أو Ink أو Core Blue فقط. ممنوع الظلال، التدرجات داخله، والتزاحم مع badges أو logo مورد. الاسم الرسمي لا يسبق بـ«د.» في الواجهات أو التواصل المؤسسي.

### الخط

Arabic UI: **IBM Plex Sans Arabic** إن توفر في build، ثم `Tahoma`, `Arial`, sans-serif. English/UI: **Inter**, ثم Arial. العناوين لا تُزخرف؛ الفارق يأتي من scale والوزن.  
Display: 40/48, 700 — H1: 32/40, 700 — H2: 24/32, 700 — body: 16/26, 400 — small: 14/22.  
الأرقام والأسعار تستخدم tabular figures حيث يسمح الخط. المحاذاة RTL أصلية؛ لا نعكس الإنجليزية داخل أرقام الأدوية أو أسماء المنتجات المعتمدة.

### الصورة والرسوم

صور فعلية للفروع، الرفوف المرتبة، أفراد الفريق أثناء مساعدة حقيقية، ولقطات قريبة للأشياء اليومية المرتبطة بالخدمة. الضوء نهاري/محايد، وزوايا واقعية، ولون أزرق موجود في البيئة لا filter أزرق فوق كل شيء. يفضل توثيق «اليد + المعلومة + المكان» على portrait رسمي للمؤسس. الرسوم خطية دقيقة بسُمك 1.75px وحواف دائرية، وظيفتها شرح المسار لا تزيين الشاشة.

## Component contracts

| Component | العقد والحالات |
|---|---|
| Primary button | أزرق Core، نص فعل واضح: «أكد التوفر على واتساب». hover أغمق، focus 3px blue ink ring، loading يحتفظ بالعرض. |
| Secondary button | Paper/outline. يستخدم للفعل الأقل أولوية فقط: «اعرف أقرب فرع». |
| Search field | label ظاهر، placeholder مثال حقيقي، زر بحث، clear state، keyboard focus. لا يَعِد بالتوفر من الكتابة وحدها. |
| Medicine card | الاسم، المادة/التركيز إن ثبت، آخر سعر معروف، timestamp، حالة التوفر، CTA واحد. لا badge تخفيض افتراضي. |
| Availability badge | `آخر تحديث` أو `محتاجين نأكد من الفرع`. لا تستخدم «متوفر» إلا من مصدر live موثوق. |
| Product detail | مصدر السعر/تاريخه، تحذير واضح أن السعر قابل للتغير، WhatsApp prefill، وعلامة وصفة عند الحاجة. |
| Branch card | اسم الفرع، العنوان، ساعات مؤكدة فقط، call / map / WhatsApp. لا تخترع بيانات فرع ثانٍ. |
| Service cue | icon + عنوان قصير + وصف قابل للتحقق. أمثلة: «قبل ما تتحرك» و«معلومة واضحة». |
| Help card | صورة/رسم صغير، سؤال مباشر، CTA إلى محادثة. لا تشخيص أو prompt طبي عام. |
| Alert | warning للبيانات التي يلزم تأكيدها؛ danger للـmedical escalation؛ لا يختفي تلقائيًا. |

## UX product rules

1. **صدق الحالة قبل اكتمال المسار.** نتائج البحث تشير إلى آخر معلومة معروفة، لا إلى stock حي ما لم يوجد تكامل موثوق.
2. **WhatsApp ليس shortcut غامضًا.** كل CTA يمرّر اسم المنتج والتركيز والفرع المختار ووقت السؤال في رسالة جاهزة قابلة للتعديل.
3. **السعر له سياق.** صيغة إلزامية: «آخر سعر معروف: 128 ج.م — محدّث 27 سبتمبر، 10:40 ص». السعر بلا timestamp غير صالح للنشر.
4. **لا تشخيص داخل البحث.** نساعد في العثور على الدواء أو توجيه السؤال للصيدلي، مع escalation هادئ للحالات الحساسة.
5. **الفرع قرار مبكر.** يظهر اختيار الفرع عند الحاجة فقط، ولا يوقف البحث قبل أن يرى المستخدم منفعة.
6. **التوصيل promise مش banner.** لا نعرض وقتًا أو نطاقًا أو تكلفة إلا إذا تم تشغيلها وتحديثها تشغيليًا.
7. **RTL أصلي.** ترتيب القراءة، محاذاة labels، arrows، وfocus order كلها RTL؛ تبقى أرقام الهاتف، الجرعات، أسماء المنتجات، وURL بصيغة LTR المقروءة.
8. **إتاحة.** text contrast WCAG AA، error text لا يعتمد على اللون، لغة واضحة، وتأكيدات واتساب قابلة للقراءة بقارئ الشاشة.

## Website information architecture

الرئيسية: بحث مباشر → كيف يعمل المسار → فئات خدمية → مساعدة صيدلي → الفروع → footer.  
البحث: query + filters غير إلزامية → نتيجة آخر معلومات معروفة → تحديد المنتج.  
المنتج: حقائق المنتج + آخر سعر/التحديث + availability CTA + التنبيه التشغيلي.  
الفروع والتواصل: cards واقعية لكل فرع + map/call/WhatsApp. لا صفحة «عنّا» طويلة في البداية؛ التاريخ والقيم يمكن أن يعيشا في جزء صغير من الصفحة أو footer.

## Social system and campaign direction

### الفكرة: «المعلومة الواضحة بتوفر مشوار»

ليست tagline دائمًا؛ هي منصة محتوى وخدمة. تُظهر كيف تجعل الصيدلية الخطوة التالية أوضح: اسم الدواء، ماذا نسأل قبل الذهاب، متى نسأل صيدليًا، وأين نجد الخدمة. الحملة تبني ثقة في النظام، لا شخصًا واحدًا.

قوالب المحتوى:

1. **اسأل قبل ما تتحرك:** carousel بسيط: المنتج/المعلومة → ما نحتاج نعرفه → WhatsApp.
2. **على الرف:** منتج أو فئة مع معلومة عملية دقيقة، بحد أقصى فكرة واحدة.
3. **من الفرع:** صورة حقيقية، خدمة متحققة، موقع واضح.
4. **نرتّبها معاك:** pharmacist/help format لحالات شائعة من غير تشخيص.

Composition: مساحة Paper، headline عربي ثقيل، خط أزرق جانبي رفيع، لقطة واحدة حقيقية أو رسم utility، timestamp/source عند الأسعار أو availability. لا gradient طبي، لا collage منتجات، لا stock-doctor، ولا founder portrait كقالب رئيسي. Instagram أولًا؛ Facebook يستخدم نفس النظام عندما يستعاد access، ولا يوقف الموقع أو WhatsApp على ذلك.

## critique and revision log

**تعديل v0.9:** Copper صار accent محدودًا للقصص والخدمات فقط، وكل information/medicine state بقيت داخل blue/neutral/status semantics. أضفنا timestamp contract ومبدأ “لا نَعِد بالتوفر” كقواعد مكوّنات لا كنسخ تحذيرية فقط. النتيجة تحافظ على إنسانية العلامة دون أن تحوّل الصيدلية إلى beauty retail.

## قرارات المالك المطلوبة فعلًا قبل الإنتاج

لا يوجد تناقض استراتيجي. يلزم فقط قبل تشغيل نسخة production:  
1. عيّنة/صورة واضحة من الأزرق الحقيقي على اللافتة لمعايرة `brand.blue.core` بدقة.  
2. بيانات موثّقة لكل فرع: الاسم، العنوان، ساعات العمل، الهاتف، رابط Maps، ونطاق/قواعد التوصيل.  
3. مصدر تشغيلي للأسعار والتوفر، أو اعتماد عبارة «آخر سعر معروف» مع مسؤول/وقت تحديث محددين.  
4. الرقم/الحساب الرسمي الذي يستقبل رسائل WhatsApp الجاهزة.
