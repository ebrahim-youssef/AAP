# Ali Amin Pharmacies — Design System v0.10

**Status:** Draft for review. It is not frozen.

## What changed

The visual direction now uses the **Useful Shelf**: a precise deep-blue rail with small segments that carries timestamps, service facts, and the next step. It turns the pharmacy shelf into an information structure instead of using medical icons, generic rounded-card grids, or a stock healthcare hero.

The system keeps the established physical blue, then adds warm paper and a controlled apricot accent. The result is modern and recognizably local without becoming clinical, beauty-led, or generic SaaS.

## Brand rules

- Arabic wordmark is primary: **علي أمين** then **صيدليات**. English is supporting metadata.
- No capsule, leaf, medical cross, heartbeat, or founder-led visual language.
- Use real branch/team/service photography when available; no stock doctor portraits or product collages.
- Voice stays imported: Egyptian Arabic, direct, informed, candid, and useful.
- Every price needs a timestamp. Availability always states whether it is confirmed or needs a branch check.

## System coverage

- DTCG-style core and light semantic tokens
- Arabic-first type, RTL behavior, responsive layout, motion and reduced-motion rules
- Contracts for button, field, card, status badge, and dialog
- Search, product-information, pharmacist-help, and branch compositions
- WCAG 2.2 AA target with validated key text/action contrast pairs
- Social direction: one Useful Shelf rail per post; one fact and one next step

## The specimen

The refreshed specimen demonstrates the designed system through a real pharmacy flow: homepage message, medicine search, latest-known price and timestamp, WhatsApp confirmation dialog, pharmacist help, and deliberately unfilled branch facts. The placeholder WhatsApp number and unverified branch information must be replaced with operating data before launch.
