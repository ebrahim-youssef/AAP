Action button; use exactly one primary per screen, labelled with a verb ("أكد التوفر على واتساب").
```jsx
<Button icon="message-circle" block>أكد التوفر على واتساب</Button>
<Button variant="secondary" block>اسأل صيدلي</Button>
```
Variants: primary, secondary, ghost, inverse (navy, on blue). Sizes md 52px / sm 40px. `loading` keeps the width.
